Semantic Data & AI Agents — FAQ

20 October 2026

Answers to common questions from GlobalFoundries (GF) teams about deploying semantic data and AI agents, who owns them, and how they improve over time.

Deployment

1.How do we deploy the semantic data?

Semantic data can be mapped autonomously using machine learning, with roughly 60–70% accuracy. The mapping draws on a few key documents:

  • P&ID in DEXPI format
  • Instrument list
  • Equipment list

Accuracy depends on how much data is available and how clean it is.

2.How do we deploy the agents?

We have already built generic agents that can run on the semantic data and shorten the time to value. They include:

  • Drift agent for ultrapure water (UPW)
  • Root cause analysis (RCA) agent

The platform also includes agent-building capabilities, so GF can create its own agents. We will co-develop more advanced agents together with GF.

3.How long does deployment take?

It depends mainly on whether the source documents are available and clean. Complete, up-to-date, structured documents make deployment faster. Missing or inconsistent documents have to be cleaned up first, which adds time.

Ownership

4.Who owns the agents?

GF owns the agents' skills and knowledge. GF teams can update the agents' skills at any time, and are encouraged to keep tuning them to GF's own "gold standard."

How the agents work

5.How is the confidence score generated?

The AI sets the confidence level as it checks each hypothesis against actual plant data, such as process data and analyzer readings. The score is based on how closely the evidence matches the hypothesis and how much evidence is available.

6.How does the agent learn and grow?

The agent can learn and grow in many ways. Two examples:

  • E-logbooks: Corrective and mitigative actions are recorded in e-logbooks. Each recorded learning becomes a new node in the semantic data, so the agent can use it in future analyses.
  • User interactions: How users interact with the agent, their behaviours and their analysis patterns can be institutionalised as knowledge the agent can draw on.
7.Where does the data for this model come from?

The model uses GlobalFoundries historical data from 2024 to 2025.

8.How does the root cause analysis agent work?

The RCA agent is grounded in existing operator knowledge and workflows. It is also instructed to carry out each investigation step on its own, so it can adapt to different scenarios.
